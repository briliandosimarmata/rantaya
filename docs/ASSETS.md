# Aset dan dependensi

Foto demo warna di web/static/assets merupakan aset sintetis/ilustratif dari prototipe percakapan sebelumnya. Nama seniman/komunitas/event dan foto dipakai sebagai data contoh, bukan klaim tentang orang atau pertunjukan sungguhan. Ganti dengan flyer/foto yang kamu/pengelola berhak gunakan untuk pilot nyata. Source tidak menyertakan brand X, Threads, Reddit atau aset situs referensi.

Font Noto Sans local menggunakan SIL Open Font License; salinan OFL-Noto-Sans.txt berada di folder assets. venue-layout.svg adalah denah ilustratif, bukan layout lokasi nyata. Icon SVG sederhana dan favicon dibuat untuk proyek. Tidak ada filter monokrom pada konten.

Dependensi utama: Go standard library; pgx (MIT); Svelte/SvelteKit/Vite (MIT); qrcode (MIT); jsQR (Apache-2.0). Tooling TypeScript (Apache-2.0), Playwright (Apache-2.0), Prettier (MIT). Dependensi transitive dan versi tepat ada di go.sum dan web/package-lock.json; lisensi dari paket terpasang tetap berlaku. Periksa lisensi ketika menambah atau memperbarui paket.

Source aplikasi diberikan untuk dilanjutkan pengguna. Tidak ditambahkan lisensi publik untuk proyek milik pengguna; tentukan lisensi sendiri sebelum memublikasikan repo. Jangan menghapus notice lisensi third-party.
